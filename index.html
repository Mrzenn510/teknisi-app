⚠️ Nama host HARUS SAMA PERSIS dengan MQTT_SERVER di kode ESP32 (sketch.ino / sketch_hardware_asli.ino). Port & path WebSocket dicoba OTOMATIS (lihat status koneksi di tab Monitoring) — beberapa broker publik dikenal (test.mosquitto.org, broker.emqx.io, broker.hivemq.com, mqtt.eclipseprojects.io) langsung pakai setelan yang benar. Broker lain akan dicoba beberapa kombinasi port umum secara berurutan.
⚙️ Advanced: port / path / username / password ▾
Isi HANYA jika kamu tahu persis port WebSocket broker-mu (bukan port 1883/8883 milik ESP32 — itu port MQTT native, beda dengan port WebSocket browser). Contoh umum: 8083/8084 (EMQX), 8000/8884 (HiveMQ), 8080/8081 (Mosquitto).
Karena app ini dibuka lewat HTTPS (github.io), browser MEMBLOKIR ws:// biasa (mixed content) — kalau broker cuma sediakan ws:// tanpa TLS, app tidak akan pernah bisa konek dari sini, apapun setelan lainnya. Pilih "Otomatis" kecuali kamu yakin butuh override.
